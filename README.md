# PlanLite

轻量级、纯本地化的 Windows 10 / Windows 11 个人工作计划管理工具。基于 C# / .NET 10 LTS 与 WPF (Fluent Design) 构建，驻留系统托盘、点击即用、零网络请求，专注于个人每日与每周工作计划管理、进度追踪及日报周报生成。

> v1.0 初始产品设计文档与性能约束可参见 [docs/PRD.md](docs/PRD.md)，后续需求变更记录与优先级决策依据可参见 [docs/REQUIREMENTS_CHANGELOG.md](docs/REQUIREMENTS_CHANGELOG.md)。

---

## 一、应用场景

PlanLite 不做复杂的多人协作、云端同步或甘特图，而是围绕个人高频办公场景保持极简与低资源占用：

- **日常托盘随手记与进度更新**：常驻 Windows 系统托盘，不占用任务栏；通过单击托盘或全局快捷键 `Alt + Shift + P` 秒级唤出窗口，记录任务或拖动进度条。
- **周目标拆解与自动汇总**：制定本周目标并拆解为每天的工作任务，支持每日任务关联周计划，由每日进度自动等权汇总本周目标进度。
- **跨天 / 跨周结转与历史追溯**：未完成任务可一键结转至下一天或下一周，完整保留原周期记录用于复盘，并支持按日期、自然周或关键词检索历史任务。
- **快速整理日报与周报**：按「已完成 / 进行中 / 未开始」一键生成结构化 Markdown 日报和周报，支持直接复制到剪贴板或导出 `.md` 文件。
- **离线 / 内网办公与绿色便携**：零网络请求、无需登录注册、无服务端依赖；支持打包为单个独立 `.exe`，搭配 `portable.flag` 即可放入 U 盘或同步盘绿色便携运行。

### 设计原则与非目标（Non-Goals）

- **轻量化与纯本地**：零网络请求、零后台高频轮询，不引入 Electron、内嵌浏览器或服务端组件，始终保持低 CPU 与内存占用。
- **专注个人日 / 周计划**：明确不包含账号注册与登录、云端数据同步、多人协作、移动端 / 网页端、复杂项目管理与甘特图，以及 AI 功能。

## 二、功能特性

### 1. 系统托盘与轻量交互
- **托盘驻留与右下角弹窗**：默认启动后静默隐藏在系统托盘；左键单击托盘图标，在当前鼠标所在显示器的工作区右下角弹出类 Windows 11 通知中心主窗口（固定宽度 `416px`、高度自适应、圆角外观）。
- **失焦自动收起与固定模式**：点击窗口外部或按 `Esc` 键自动隐藏并自动保存未落盘改动；点击右上角图钉按钮或在托盘右键菜单勾选「固定窗口」后，窗口保持常驻显示。
- **托盘右键菜单**：支持「打开主窗口」「固定窗口」「迷你悬浮窗」「日报 / 周报」「设置」「退出」。
- **单实例与跨天自动刷新**：通过本地互斥锁与命名管道保证单实例运行（重复启动时自动激活已有窗口）；内置零点定时器及系统时间/休眠唤醒事件监听，跨天后自动刷新当日视图，无高频后台轮询。

### 2. 三大主视图：总览 / 今日计划 / 本周计划
- **总览视图**：同屏展示本周计划汇总进度与今日计划列表，支持快捷输入框回车新增今日任务、勾选快速完成及滑块调整进度。
- **今日计划**：
  - 支持「前一天 / 今天 / 后一天」日期切换，查看或提前制定工作计划。
  - 支持回车快捷添加并可选关联当前自然周的某项周计划。
  - 支持列表卡片拖拽调整排序，点击任务标题打开**内联任务详情面板**（编辑标题、备注、调整关联周计划、进度滑块与 `0% / 50% / 100%` 快捷按钮、上移/下移、删除二次确认），且内联编辑不会触发窗口失焦隐藏。
  - 勾选复选框一键标记完成；取消勾选时自动恢复完成前的原进度；已完成任务自动折叠降低视觉干扰。
  - 支持一键**「结转未完成至下一天」**：非破坏性复制未完成任务到下一天并记录结转来源，重复点击幂等跳过已结转任务。
- **本周计划**：
  - 按 ISO-8601 自然周（周一至周日）管理工作目标，支持切换周次、卡片拖拽排序与一键**「结转未完成至下周」**。

### 3. 每日任务与周计划关联 & 状态联动
- **两种周计划进度模式**：
  - **手动模式**：手动拖动滑块或快捷勾选更新周计划进度。
  - **自动计算模式**：按所有关联到该周计划的每日任务进度进行等权平均（四舍五入），任一关联每日任务的创建、进度变更、改绑或删除均会在同一事务内自动重算周计划进度；删除周计划时保留已关联的每日任务并自动解除关联。
- **进度与状态自动联动**：任务进度范围为 `0% ~ 100%`，其中 `0%` 自动对应「未开始」、`1% ~ 99%` 对应「进行中」、`100%` 对应「已完成」并记录完成时间。

### 4. 迷你悬浮窗（可选，默认关闭）
- 在托盘菜单或设置中开启后，在桌面边缘置顶显示精简悬浮条，实时展示今日完成任务数、平均进度条及当前活跃任务标题。
- 支持鼠标按住自由拖动，靠近屏幕边缘自动吸附并记住上次位置；单击直接展开主窗口。

### 5. 历史记录与关键词搜索
- **按周期分页浏览**：支持在「按日期浏览」与「按自然周浏览」间切换，查看各周期任务数量、完成率及平均进度，点击直接跳转到对应日期或周次视图。
- **关键词检索**：支持按任务标题或备注关键词搜索历史每日与每周计划，点击搜索结果可直达对应周期。

### 6. 日报与周报生成
- 支持切换「工作日报」与「工作周报」，并支持前后切换任意日期或周次。
- 自动统计汇总数据，并按「已完成 / 进行中 / 未开始」分类生成 Markdown 文本（含任务进度、关联周计划及多行备注）。
- 支持**一键复制 Markdown** 到剪贴板，以及**导出 `.md` 文件**。

### 7. 软件设置、自动保存与备份恢复
- **外观主题**：支持「跟随系统」「浅色」「深色」三种 Fluent Design 主题。
- **全局快捷键**：默认 `Alt + Shift + P`，支持在设置页开启/关闭、点击输入框直接录制新组合键以及一键恢复默认。
- **开机自启动**：通过写入当前用户注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 实现（无需管理员权限）。
- **自动保存与本地备份恢复**：所有改动自动持久化至 SQLite（WAL 模式）与原子写入的 JSON 配置文件；支持导出 `.zip` 完整备份包（含数据库、配置文件及清单），恢复时执行数据库完整性校验并自动保留 `planlite.pre-restore.db` 恢复前副本。

## 三、技术栈与项目结构

### 技术栈

| 类别 | 选型 / 版本 | 说明 |
|---|---|---|
| 运行平台 | Windows 10 / Windows 11 (x64) | 原生桌面客户端，无 Electron / WebView / 后台服务 |
| 开发语言与运行时 | C# / .NET 10 LTS (`net10.0`、`net10.0-windows`) | 支持单文件自包含发布 |
| 桌面 UI 框架 | WPF + `WPF-UI` (`4.3.0`) + `WPF-UI.Tray` (`4.3.0`) | Fluent Design 风格与系统托盘图标 |
| 架构模式 | MVVM (`CommunityToolkit.Mvvm` `8.4.2`) | 视图、ViewModel 与核心业务解耦 |
| 数据存储 | SQLite (`Microsoft.Data.Sqlite` `11.0.0`) | 启用 WAL 模式与外键约束 |
| 配置与序列化 | `System.Text.Json` | `settings.json` 原子写入与备份清单 |
| 单元测试 | xUnit (`2.9.3`) + `Microsoft.NET.Test.Sdk` (`18.12.0`) | 覆盖周计算、仓储逻辑、报表、设置与备份恢复 |
| 构建与发布 | .NET CLI + PowerShell (`scripts/publish.ps1`) | 生成绿色便携单文件 `PlanLite.exe` |

```text
PlanLite/
```

## 四、开发与编译

### 1. 环境准备
- **操作系统**：Windows 10 / Windows 11 (x64)
- **SDK**：[.NET 10.0 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)
- **IDE（可选）**：Visual Studio 2022+、JetBrains Rider 或 VS Code

### 2. 编译、测试与运行

在仓库根目录执行以下命令：

```powershell
# 还原依赖并编译整个解决方案（Release）
dotnet build PlanLite.sln -c Release

# 运行 Core 层单元与集成测试
dotnet test tests/PlanLite.Core.Tests/PlanLite.Core.Tests.csproj -c Release --no-build

# 启动调试运行并立即显示主窗口（不带 --show 时默认隐藏在托盘）
dotnet run --project src/PlanLite/PlanLite.csproj -- --show
```

> **多版本 .NET SDK 提示**：若系统全局 `PATH` 中的 `dotnet` 指向旧版本 SDK，而 .NET 10 SDK 安装在 `%LocalAppData%\Microsoft\dotnet`，可在 PowerShell 中显式指定工具链路径：
>
> ```powershell
> $env:DOTNET_ROOT = "$env:LOCALAPPDATA\Microsoft\dotnet"
> $dotnet = "$env:LOCALAPPDATA\Microsoft\dotnet\dotnet.exe"
>
> & $dotnet build PlanLite.sln -c Release
> & $dotnet test tests/PlanLite.Core.Tests/PlanLite.Core.Tests.csproj -c Release --no-build
> ```

### 3. 打包单文件绿色 EXE

使用仓库自带发布脚本生成不依赖本机 .NET Runtime 的单文件可执行程序：

```powershell
.\scripts\publish.ps1
```

默认会在 `artifacts\publish\PlanLite.exe` 生成压缩后的单文件 `win-x64` 自包含程序（已内嵌图标与 SQLite 原生库）。也支持传入常用参数：

```powershell
# 跳过 NuGet 还原并自定义输出目录
.\scripts\publish.ps1 -NoRestore -OutputDir dist
```

## 五、使用指南

### 1. 启动与唤出窗口
- **常规启动**：双击运行 `PlanLite.exe`，软件静默启动并驻留在系统托盘（右下角通知区域）。
- **启动即显示**：在快捷方式或命令行传入 `--show` 参数（例如 `PlanLite.exe --show`），启动后立即弹出主窗口。
- **呼出与隐藏**：
  - 左键单击托盘图标，或按下全局快捷键 **`Alt + Shift + P`**（默认）即可呼出/收起主窗口。
  - 点击窗口外部或按 `Esc` 键会自动隐藏窗口；若需持续查看，可点击窗口右上角「图钉」按钮固定窗口。
  - 右键托盘图标可快速打开主窗口、切换固定状态/迷你悬浮窗、直达「日报 / 周报」或「设置」，以及退出软件。

### 2. 日常使用流程
1. **制定周目标**：切换到「本周计划」，输入目标后回车添加；若希望由每日任务自动汇总完成度，勾选「自动计算进度」。
2. **安排每日任务**：在「总览」或「今日计划」输入当日任务并回车创建；在「今日计划」中还可选择关联某条周计划，并直接拖动卡片调整优先级顺序。
3. **更新进度与编辑详情**：
   - 勾选任务左侧复选框快速完成/取消完成；
   - 直接拖动任务卡片底部的进度滑块调整进度（`0%–100%`）；
   - 点击任务标题打开详情面板，可补充多行备注、更改关联周计划、切换手动/自动模式、上移/下移或删除任务，所有操作均自动保存。
4. **跨天 / 跨周结转**：在「今日计划」点击「结转未完成至下一天」，或在「本周计划」点击「结转未完成至下周」，未完成任务会自动复制到下一周期，历史记录完整保留且不会重复结转。
5. **生成日报与周报**：点击主窗口底部「日报 / 周报」，选择日报或周报及对应周期，即可一键复制 Markdown 或导出 `.md` 文件。
6. **查阅历史记录**：点击底部「历史记录」，按日期/自然周浏览过往完成情况，或输入关键词快速检索标题与备注。
7. **使用迷你悬浮窗**：在托盘右键菜单或「设置」中开启「迷你悬浮窗」，可将其拖动并吸附至屏幕任意边缘，单击即可呼出主窗口。

### 3. 数据存储位置与绿色便携模式

PlanLite 支持**程序与数据分离**和**绿色便携**两种存储模式：

- **默认模式（程序与数据分离，升级程序不丢失数据）**  
  数据默认存储在：
  ```text
  %LocalAppData%\PlanLite\
  ```
- **绿色便携模式**  
  在 `PlanLite.exe` 所在同级目录下新建一个名为 `portable.flag` 的空文件后重启程序，所有数据会自动切换至程序旁边的独立目录：
  ```text
  <PlanLite.exe 所在目录>\data\
  ```

数据目录中包含以下文件：
- `planlite.db`：SQLite 工作计划数据库（WAL 模式）。
- `settings.json`：主题、快捷键、窗体固定、悬浮窗位置与开机自启等配置。
- `logs\error.log`：仅在发生未处理异常时自动创建的本地错误日志。

### 4. 数据备份与迁移
1. 打开主窗口右上角「设置」→「数据存储与备份」。
2. 点击**「备份数据」**，选择保存路径即可导出 `.zip` 备份包（内含数据库、配置文件及版本清单）。
3. 在新设备或重装系统后，点击**「恢复数据」**并选择 `.zip` 备份包，确认后即可完成校验与恢复（系统会自动在数据目录保留一份 `planlite.pre-restore.db` 恢复前副本以防误操作）。
