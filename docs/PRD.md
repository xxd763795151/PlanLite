# Windows 轻量级工作计划管理工具 PRD

> **归档说明**：本文档为 PlanLite v1.0 初始产品设计文档，用于记录核心设计原则、性能约束与产品边界；后续功能更新与使用说明请以根目录 [README.md](../README.md) 及 GitHub Releases 为准。

## 1. 项目概述

### 1.1 项目背景

开发一款 Windows 平台下的个人工作计划管理工具，用于记录每周、每日工作计划，跟踪任务进度及完成情况，方便日常工作管理、工作回顾以及日报、周报整理。

### 1.2 产品定位

一个简单、美观、小巧、低资源占用的本地桌面工具。

核心设计原则：

- 轻量化，尽可能减少 CPU 和内存占用。
- 操作简单，减少不必要的交互步骤。
- 界面美观，采用现代化 Windows UI 风格。
- 数据完全本地化，无需网络及服务端。
- 无需注册、登录，不涉及多人协作。

## 2. 产品形态

### 2.1 系统托盘

- 软件启动后默认隐藏在 Windows 系统托盘中，不占用任务栏。
- 单击托盘图标，在屏幕右下角弹出主窗口。
- 再次点击图标或点击窗口外部，自动隐藏窗口。
- 支持固定窗口，固定后不自动隐藏。
- 右键托盘图标提供打开窗口、设置、退出等操作。

### 2.2 主窗口

采用类似 Windows 11 通知中心的设计风格：

- 圆角、阴影、简洁布局。
- 默认宽度约 400px，高度根据内容自适应，支持滚动。
- 支持浅色、深色以及跟随系统主题。
- 提供总览、今日计划、本周计划三个视图。
- 支持通过全局快捷键唤出窗口。

### 2.3 迷你悬浮窗口

可选功能，默认关闭。

在桌面边缘展示一个小型悬浮窗口，显示今日任务完成数量、总体进度以及当前正在进行的任务，点击后展开主窗口。

## 3. 功能需求

### 3.1 每周工作计划

- 按自然周管理工作计划，周一至周日为一个周期。
- 支持切换查看不同周的工作计划。
- 支持新增、编辑、删除、排序。
- 支持设置任务标题、备注、进度及状态。
- 支持手动更新任务进度。
- 支持直接标记为已完成。
- 支持将未完成任务结转至下一周。
- 展示本周整体任务完成情况。

### 3.2 每日工作计划

- 按日期管理每日工作计划。
- 默认展示当天的工作计划。
- 支持切换日期，查看或提前制定工作计划。
- 支持新增、编辑、删除、排序。
- 支持快速勾选完成。
- 支持更新任务进度及备注。
- 支持将未完成任务结转至下一天。
- 展示当日任务完成数量及总体进度。

### 3.3 任务关联

每日工作计划可以选择关联某个周计划，也可以独立存在。

周计划支持两种进度更新方式：

- 手动更新：由用户直接设置进度。
- 自动计算：根据关联的每日任务进度计算。

自动计算默认采用等权平均方式。

### 3.4 任务状态

| 状态 | 说明 |
|---|---|
| 未开始 | 任务尚未开始 |
| 进行中 | 任务正在处理 |
| 已完成 | 任务已经完成 |

任务进度范围为 0～100%。

进度为 0% 时对应未开始，1%～99% 对应进行中，100% 对应已完成。

### 3.5 历史记录

- 支持按日期、周查看历史工作计划。
- 自动保留历史任务及完成情况。
- 支持按任务关键词搜索。
- 跨天、跨周时不自动删除或清空历史计划。

任务结转时保留原周期的历史记录。

### 3.6 日报与周报

- 根据每日工作计划生成日报。
- 根据每周工作计划生成周报。
- 包含已完成、进行中、未完成任务及相关备注。
- 支持一键复制到剪贴板。
- 支持导出为 Markdown 格式。

### 3.7 自动保存

- 所有任务修改自动保存，无需手动点击保存按钮。
- 软件退出、系统重启后数据不丢失。
- 支持本地数据备份与恢复。

### 3.8 软件设置

- 开机自启动。
- 全局快捷键设置。
- 浅色、深色、跟随系统主题切换。
- 窗口固定设置。
- 迷你悬浮窗口开关。
- 数据存储位置查看。
- 数据备份与恢复。

## 4. 界面设计

### 4.1 总览页面

主窗口主要分为以下区域：

- 顶部：软件名称、当前日期、星期、周数、设置按钮。
- 导航区：总览、今日、本周。
- 本周计划区：任务名称、任务进度条、完成状态。
- 今日计划区：任务名称、完成勾选框、进度。
- 底部：历史记录、日报周报入口。

### 4.2 交互设计

- 点击任务名称可以查看或编辑任务详情。
- 点击完成按钮快速标记任务完成。
- 点击进度值或拖动进度条更新进度。
- 支持快捷添加任务。
- 支持拖拽调整任务顺序。
- 已完成任务降低视觉突出程度，支持折叠展示。
- 未完成任务优先展示。

## 6. 非功能性需求

### 6.1 性能及资源占用

以下为初步性能目标，最终以实际测试结果为准。

| 指标 | 目标 |
|---|---|
| 空闲 CPU 占用 | 接近 0% |
| 托盘隐藏时内存占用 | 尽量控制在 50 MB 以内 |
| 窗口展示时内存占用 | 尽量控制在 100 MB 以内 |
| 软件启动时间 | 2 秒以内 |
| 主窗口唤出时间 | 200 ms 以内 |
| 后台网络请求 | 无 |

实现要求：

- 采用事件驱动机制，避免高频轮询。
- 窗口隐藏时停止不必要的渲染及动画。
- 避免长期运行导致的内存泄漏。
- 按需加载历史数据。
- 尽量减少第三方依赖。

### 6.2 数据安全

- 所有业务数据存储于本地。
- 不上传用户数据。
- 不进行在线行为统计。
- 备份文件支持直接迁移至其他电脑。

### 6.3 部署要求

- 支持绿色便携运行，无需安装。
- 支持独立 EXE 发布，无需额外安装 .NET Runtime。
- 不需要管理员权限。
- 程序文件与用户数据分离，升级程序时不影响已有数据。
